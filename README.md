# spidiboost.SpidiCard

Minecraft 1.21.4 · Fabric · Java 21 · Fabric API

Главный владелец: **SpidiBoost**.

Публичный репозиторий распространения: [скачать последнюю версию](https://github.com/SpidiBoostMods/SpidiCard/releases/latest).

Требуется подписка от SpidiBoost: пробная на 7 суток с момента выдачи, до определённой даты либо бессрочная. Один раз нажмите «Подключить подписку» на экране активации — это нужно и при уже выданном доступе. Экран объясняет регистрацию кода устройства, имени пользователя ОС и имени компьютера в закрытом реестре владельца. Исходный идентификатор машины не передаётся.

В 1.7.0 подписка проверяется при запуске, каждом входе на сервер и раз в 30 секунд одним фоновым исполнителем. При недоступности основного сервиса используется независимый резерв Google. Пробный доступ показывает оставшееся время; обычные сообщения не содержат служебных кодов.

В 1.7.1 выдача, отзыв, смена типа подписки и продление показываются отдельным меню после ближайшей проверки. Истечение срока показывает меню сразу. `/spidicard sub` выводит информацию только в чат, без title и браузера, включая отсутствие подписки и отозванный доступ.

При истечении срока появляется меню подписки, активный поиск завершается с сохранением найденных ников. Попытка запустить недоступную команду показывает красное уведомление и открывает [VK SpidiBoost](https://vk.ru/paveljaparov); `/spidicard sub` выводит информацию только в чат. Обновления доступны без действующей подписки: `/spidicard update`. Алиас `/spidicart` удалён.

Исходники лицензируемой версии и реестр пользователей хранятся в закрытых репозиториях. Публичные релизы содержат защищённый JAR и manifest обновления. Система лицензирования применяется к 1.6.0 и новым версиям; старые выпуски не содержат этой проверки. Абсолютной защиты Java-клиента от модификации нет.

Обновлятор сохраняет настройки и результаты, делает резервные копии и устанавливает обновления после завершения игры. Если запуск лаунчера нельзя безопасно повторить, требуется обычный повторный запуск через лаунчер.

`/spidicard update on|off` включает или отключает автоматический перезапуск, как в 6ubaaFP. Скачивание обновлений остаётся включённым. Настройка общая для установленных модов SpidiBoost. С 1.7.2 SpidiCard не регистрирует и не перехватывает общую команду `/update`.

Меню списка установленных модов появляется в обоих режимах on/off. При готовом обновлении off позволяет продолжить игру, on запускает автоматический перезапуск, когда безопасный запуск лаунчера определён.

`/spidicard menu` открывает результаты внутри Minecraft. Доступны выделение мышью, Cmd+C/Ctrl+C, контекстное меню правой кнопки, копирование всего текста и открытие папки. Окно автоматически появляется после start/full, остановки и разрыва соединения; уже найденные ники сохраняются. Пустые грифы скрыты.

Панель поиска по умолчанию находится над хотбаром. Откройте чат своей назначенной клавишей и перетащите панель левой кнопкой; положение сохраняется. Дублирующие сообщения о прогрессе убраны.

Счётчик full учитывает выбранный маршрут: для 1–4 отображается `ГРИФ 1/4`; для списка `53,56` — `ГРИФ #53 · 1/2`, с реальным номером сервера и позицией в маршруте.
